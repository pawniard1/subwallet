# Subscriptions

A subscription tracker that runs in the browser. Data is saved on the device (localStorage) and never leaves it.

## Put it on GitHub Pages (no Mac, no command line)

1. On github.com, tap **+** then **New repository**. Name it (for example `subscriptions`), keep it **Public**, and create it.
2. Tap **Add file**, then **Upload files**. Upload everything from this folder: `index.html`, `manifest.json`, `icon-180.png`, `icon-512.png` and `.nojekyll`. Commit.
3. Go to **Settings**, then **Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main**, folder **/ (root)**, and Save.
4. After a minute your site is at `https://YOUR-USERNAME.github.io/subscriptions/`.
5. On iPhone, open that link in Safari, tap Share, then **Add to Home Screen**.

Each device keeps its own data. There is no sync or export yet.
